# Unilever Group — Financial Analysis (FY2020–FY2021)

A Microsoft Excel portfolio project examining Unilever Group's financial performance across FY2020 and FY2021. The analysis combines financial statements, common-size statements, and key financial ratios to assess profitability, liquidity, solvency, and operating efficiency, and to identify changes in financial position over the period.

## Objective

Evaluate how Unilever Group's financial performance and position changed between FY2020 and FY2021. The project uses structured statement analysis and financial ratios to identify meaningful trends, highlight relative strengths and potential areas of concern, and support evidence-based interpretation.

## Analysis Covered

- **Financial statement analysis:** Review of the group's financial statements for the selected period.
- **Common-size analysis:** Expressing relevant statement items as a proportion of a common base to compare financial structure between years.
- **Profitability analysis:** Examining profit performance and related margins or return measures available in the workbook.
- **Liquidity analysis:** Assessing the group's ability to meet short-term obligations using the ratios provided.
- **Solvency analysis:** Reviewing leverage and longer-term financial risk indicators.
- **Efficiency analysis:** Interpreting resource and operating efficiency measures available in the workbook.
- **Comparative interpretation:** Identifying movements between FY2020 and FY2021 and considering what those changes may indicate.

Financial ratios should be interpreted in context and compared with consistent reporting definitions; where the project is used for formal work, verify figures against Unilever's original annual reports and notes.
