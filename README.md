# Unilever Group — Financial Analysis (FY2020–FY2021)

An Excel-based financial analysis project evaluating Unilever Group's performance between FY2020 and FY2021. The workbook combines consolidated financial statements, common-size analysis, financial ratios, interpretation, and a performance dashboard to highlight changes in profitability, liquidity, solvency, and operational efficiency.

## Project Snapshot

| Attribute | Details |
|---|---|
| Company | Unilever Group |

| Reporting currency | Euro (€), figures presented in millions in the financial statement sheets |

## Objective

Compare Unilever Group's financial performance and position across FY2020 and FY2021. Use common-size statements and ratio analysis to identify important year-over-year movements, evaluate the company's financial strengths and potential risks, and communicate the findings in a clear dashboard.

## Workbook Contents

The supplied Excel file contains seven worksheets:

1. **COVER PAGE** — project overview and navigation.
2. **METHODOLOGY** — project objective and analytical approach.
3. **Financial Statement** — consolidated income statement, balance sheet, and cash-flow statement information for FY2020 and FY2021.
4. **Common Size Financial Statement** — common-size statement analysis and year-over-year differences.
5. **Ratios Analysis** — financial ratio calculations and supporting measures.
6. **Ratio Analysis & Interpretation** — written analysis of profitability, liquidity, solvency, and efficiency ratios.
7. **Unilever Financial Performance** — dashboard summarizing performance indicators for FY2020–FY2021.

## Analysis Covered

- **Financial statement analysis:** Review of income, financial position, and cash flows.
- **Common-size analysis:** Compare statement structure by expressing items relative to a common base.
- **Profitability:** Evaluate profit performance and margins using the ratios included in the workbook.
- **Liquidity:** Review selected indicators of short-term financial strength.
- **Solvency:** Assess leverage and longer-term financial risk indicators.
- **Efficiency:** Consider operating and asset-use measures covered by the workbook.
- **Performance dashboard:** Bring selected metrics and year-over-year movements into one view.

## How to Use

1. Download `Unilever_Group_Financial_Analysis_FY2020_FY2021.xlsx`.
2. Open it in Microsoft Excel for the intended formatting and formulas.
3. Start with **COVER PAGE** and **METHODOLOGY**.
4. Review **Financial Statement**, **Common Size Financial Statement**, and **Ratios Analysis** for calculations and source figures.
5. Read **Ratio Analysis & Interpretation** and finish with the **Unilever Financial Performance** dashboard.
